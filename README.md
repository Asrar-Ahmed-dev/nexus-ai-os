# Nexus AI OS

An intelligent AI Operating System built using **Next.js**, **FastAPI**, **Gemini AI**, and **SQLite**.

---

## Features

- 💬 AI Chat Interface
- 🧠 Conversation Memory (SQLite)
- ⚡ FastAPI Backend
- 🎨 Modern Next.js UI
- 📄 Markdown Responses
- ⌨️ Typing Indicator
- 💾 Chat History
- 🔒 Clean Project Structure

## Installation

### Clone

```bash
git clone https://github.com/Asrar-Ahmed-dev/nexus-ai-os.git
```

### Backend

```bash
cd backend

python -m venv venv

venv\Scripts\activate

pip install -r requirements.txt

uvicorn main:app --reload
```

### Frontend

```bash
cd frontend

npm install

npm run dev
```
